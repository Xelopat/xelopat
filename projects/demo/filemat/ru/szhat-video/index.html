Сжать видео

Сжать видео онлайн: видео пересжимается кодеком H.264 через FFmpeg, на выходе - MP4, совместимый с любыми устройствами и мессенджерами. Битрейт подбирается под целевой размер. Бесплатный лимит - файлы до 100 МБ, подходит для коротких роликов.

Файлы выбраны Проверьте список перед запуском
    Поддерживаемые форматы: mp4, mov, avi, mkv, webm, m4v, 3gp

    Файлы временно обрабатываются, доступны только по приватной ссылке и удаляются автоматически.

    Как пользоваться

    1. Загрузите видео размером до 100 МБ.
    2. Укажите нужный размер в МБ.
    3. Нажмите «Конвертировать» и дождитесь окончания обработки.
    4. Скачайте результат по приватной ссылке - файл удаляется автоматически.

    Частые вопросы

    Какой формат будет на выходе?

    MP4 с видеокодеком H.264 и аудио AAC - воспроизводится на телефонах, компьютерах, в браузерах и мессенджерах.

    Сохранится ли звук?

    Да, звуковая дорожка пересжимается вместе с видео и остаётся синхронной.

    Насколько упадёт качество?

    Зависит от целевого размера: чем сильнее сжатие, тем ниже битрейт. Для отправки в мессенджеры потери обычно незаметны.

    Безопасно ли загружать файлы?

    Да. Файл передаётся по HTTPS, доступен только по приватной ссылке и удаляется автоматически: для гостей - в течение часа после обработки.

    Сколько стоит конвертация?

    Бесплатно: до 10 конвертаций в день без регистрации, размер файла - до 100 МБ. Ограничения защищают сервис от перегрузки.
